## Diagnostic misses (2 Oct)

### SDLC models

- **Core idea:** the Spiral model puts risk analysis in every iteration. It suits large, high-risk projects.
- **Exam points:** Waterfall = sequential, fixed requirements. V-model = a testing phase paired with each development phase. Prototype = unclear requirements. Incremental = delivered in pieces. Agile/Scrum = short iterations (sprints). Big Bang = no planning, tiny projects.
- **Common mistake:** choosing V-model because it emphasizes verification. Risk is the Spiral keyword.
